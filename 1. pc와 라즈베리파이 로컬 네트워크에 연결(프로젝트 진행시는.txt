1. pc와 라즈베리파이 로컬 네트워크에 연결(프로젝트 진행시는 타일스케일로연결함)

2. 라즈베리파이에 라이다 stm32 연결 (카메라는 옵션)

3. 라즈베리파이에서 터미널을 ros 환경으로설정하고
- micro_ros_agent
- LiDAR
- wheel_odom
- Custom EKF
- Network Watchdog
- AMCL
- Nav2
- Collision Monitor
해당 역할을 하는 노드들을 실행해야함
mapping_bringup mapping.launch.py 라는 명령어를 치면 전부 실행됨(안전한 연결을 위해서 20초 이상 소요)
그리고 카메라 작동을 원하면 udp로 따로 전송하는 명령을 켜야함
"source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash
ros2 launch mapping_bringup mapping.launch.py"

4. pc에서 켜야할 것들(pc가 젤 문제 초기화하면 남는 프로그램이 없음) 
- /pc_heartbeat 10Hz : 라즈베리파이와 연결 지속적으로 확인하는 프로그램(이게 없으면 연결 끊겼을 경우 오작동 방지를 위해 라즈베리파이 자체적으로 정지 명령을 쏘게 만들었음)
- ManagerScreen : 관리자 화면 응용프로그램 git에 올라가 있고 작동 테스트만 하려면 필요 없음
- RViz2 : 마찬가지로 그냥 따로 설치하면됨 라즈베리파이에서 측정한 맵이랑 라이다 현재 위치 경로 등을 표시해주는 역할만함

ros2 topic pub -r 10 /pc_heartbeat std_msgs/msg/Empty "{}"   -- 일단 이거만 실행하고 파이랑 연결하면 기본적인 동작은 가능 (명령어로 전진 후진 그런것들)

5. 웹 서버 실행
같은 pc에서 웹서버를 실행하면됨 이것도 깃에 올라가있음
실행시 핸드폰 및 다른 기기에서 접속이 가능해짐
해당 기기에서 특정 좌표로 이동하는 명령을 쏘면 라즈베리파이에서 받아서 동작(서버는 라즈베리파이랑 로컬 네트워크에 연결되어야 ros 시스템에서 인식이 가능함) 


6. 기타 설정
현재 ros 네트워크 연결이 타일스케일 기반 ip 주소로 되어있어서 
피어 연결 설정을 다른곳에서 테스트하는 ip 주소로 변경이 필요함
그리고 하트비트 신호를 못받으면 차가 안움직이므로 하트비트 신호가 가는지 연결확인이 먼저 필요
